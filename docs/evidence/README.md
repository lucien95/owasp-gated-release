# Evidence

Everything here was produced by running this repository, and nothing is staged or mocked. Each file is linked from the chapter page that explains it.

- One folder per chapter: `ch-00/`, `ch-01/`, …
- File names: `NN-SS-short-description.ext` (chapter, step, description)
- Raw screenshots land in `_inbox/`, which Git ignores, and move here only after the redaction checklist in [the documentation standard](../DOCUMENTATION_STANDARD.md).
- Results are lab measurements on a local cluster, not production data.
